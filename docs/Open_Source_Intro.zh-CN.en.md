# PinFix Open Source Intro

## English

PinFix is a lightweight web page annotation helper for product owners, designers, testers, and non-programmers.

It lets you select parts of a real web page, attach numbered labels, write change notes, and export a clean screenshot plus structured text for Codex, AI coding tools, or developers.

### Why PinFix

Many web change requests start as messy screenshots with arrows, circles, and long messages. PinFix keeps that workflow familiar, but makes it cleaner:

- Select a real page module.
- Add a numbered marker.
- Write the change request next to it.
- Copy structured notes.
- Export or prepare a clean screenshot without the tool UI.

### First Version Scope

The first version is planned as a Tampermonkey userscript.

It focuses on visible-page annotation and structured text export. Native full-page screenshots and advanced browser capture may come later in a Chrome or Edge extension version.

### Privacy

PinFix is designed to keep data local by default. Annotation notes and settings should be stored in the user's browser unless the user explicitly exports them.

## 简体中文

PinFix 是一个轻量网页标注助手，中文名可以叫“点改”。

它适合产品负责人、设计师、测试人员、独立开发者，以及不会写代码但需要清楚表达网页修改意见的人。

### PinFix 解决什么问题

很多网页修改需求都是从截图开始的：红框、箭头、编号、文字说明。这个方法很直观，但容易乱，也容易漏掉页面地址、编号对应说明、背后业务逻辑。

PinFix 保留这种直观方式，但把流程整理得更清楚：

- 在真实网页上点选模块。
- 自动添加编号。
- 在标注旁边写修改要求。
- 复制整理好的文字说明。
- 导出或准备一张不包含工具栏的干净截图。

### 第一版范围

第一版计划做成油猴脚本。

它重点支持当前可见页面的标注和文字导出。完整长图截图、浏览器原生截图、资料包导出等功能，可以等后续升级成 Chrome 或 Edge 扩展时再考虑。

### 隐私

PinFix 默认应该把数据保存在用户本机浏览器里。除非用户主动导出，否则不上传标注内容和页面信息。
