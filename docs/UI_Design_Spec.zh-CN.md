# PinFix UI 设计规格

## 1. 设计目标

PinFix 的界面应该像一个轻量标注工具，而不是开发调试工具。

关键词：

- 无感。
- 精致。
- 清楚。
- 不挡页面。
- 不需要学习成本。

用户打开网页后，PinFix 不应该抢注意力。只有当用户点击左侧入口按钮后，它才进入工作状态。

## 2. 视觉方向

整体风格建议：

- 浅色玻璃感面板，但不要过度透明。
- 暗色描边和轻微阴影，保证在各种网页背景上可见。
- 按钮使用圆角，但不要太圆。
- 工具栏紧凑，像专业截图工具或设计工具的浮动工具条。
- 支持亮色页面和暗色页面自动适配。
- 标注框和编号必须比工具栏更醒目，因为截图里最重要的是标注信息。

不建议：

- 大面积渐变。
- 很大的弹窗。
- 花哨动画。
- 过多文字说明。
- 一进页面就展开完整工具栏。

## 3. 色彩系统

基础颜色：

- 主色：深青色 `#0F766E`。
- 主色悬停：`#115E59`。
- 面板背景：`rgba(255, 255, 255, 0.92)`。
- 深色文字：`#102A2A`。
- 次级文字：`#64748B`。
- 边框：`rgba(15, 118, 110, 0.18)`。
- 阴影：`0 12px 32px rgba(15, 23, 42, 0.16)`。

暗色页面面板颜色：

- 面板背景：`rgba(15, 23, 42, 0.88)`。
- 深色页面文字：`#F8FAFC`。
- 深色页面次级文字：`#CBD5E1`。
- 深色页面边框：`rgba(148, 163, 184, 0.28)`。

标注预设：

- 红色重点：`#E11D2E`。
- 蓝色建议：`#2563EB`。
- 绿色确认：`#16A34A`。
- 黑白中性：`#111827`。

每个颜色预设要同时影响：

- 标注框线。
- 标签背景。
- 备注输入框边框。
- 当前工具状态。

可读性要求：

- 标注框不能只靠单层颜色显示。
- 亮色背景上使用彩色外框 + 深色细描边。
- 暗色背景上使用彩色外框 + 白色细描边。
- 标签必须有反差描边和阴影，不能直接贴在页面背景上。

## 4. 左侧启动按钮

默认状态只显示一个入口按钮。

规格：

- 固定定位：左侧中间。
- 点击区：约 36px × 36px。
- 形态：双圆点，外圈约 28px，内点约 12px。
- 对齐：内点必须在外圈中心，不能偏上、偏左或偏右。
- 文本：不显示 `PF` 或其他字母。
- 背景：外圈白色半透明，内点使用主色。
- 阴影：轻微悬浮阴影，但不能形成竖向胶囊。

状态：

- 默认：低调显示。
- 悬停：按钮稍微变亮，图标变主色。
- 激活：入口隐藏，显示左侧工具栏。

简体中文 tooltip：

- `打开点改`
- `关闭点改`

英文 tooltip：

- `Open PinFix`
- `Close PinFix`

## 5. 工具栏

工具栏展开在启动按钮下方。

布局：

- 竖向排列。
- 每个按钮 40px 到 44px。
- 按钮间距 8px。
- 面板内边距 8px。
- 面板圆角 16px。
- 关闭按钮放在工具栏右上角，默认隐藏。
- 鼠标移入工具栏或键盘聚焦工具栏时显示关闭按钮。
- 关闭按钮约 22px × 22px，叉号必须在圆圈中心。

主按钮顺序：

1. 选择。
2. 样式。
3. 截图。
4. 复制。
5. 更多。

按钮收纳：

- 样式按钮打开小浮层，里面放颜色、粗细、标签大小、亮页/暗页模式。
- 截图按钮打开小浮层，里面放截图准备、导出 PNG、复制图片。
- 更多按钮打开小浮层，里面放撤销、删除、标注清单、隐藏备注、清空本页、语言和设置。
- 退出标注模式由左侧主按钮负责，不长期占工具栏位置。

按钮状态：

- 默认：白底深色图标。
- 悬停：浅青色背景。
- 激活：主色背景白色图标。
- 禁用：透明度降低，不可点击。

每个按钮都必须有 tooltip。

浮层设计：

- 浮层宽度控制在 220px 到 280px。
- 浮层从工具栏旁边展开，不要盖住大面积页面。
- 浮层打开时要有清晰标题，比如“样式”或“截图”。
- 点击页面空白处自动关闭浮层。
- 当前设置要用勾选、色块或高亮状态表示，不能只靠文字说明。

## 6. 标注框

标注框是 PinFix 最重要的视觉元素。

规格：

- 框线默认 4px。
- 框线在元素外侧显示，尽量不压住原内容。
- 框线使用双层描边，外层是标注色，内层根据背景自动切换白色或黑色。
- 框线带轻微外发光，避免复杂背景下看不清。
- 已创建标注框右上角显示 3 个操作按钮：写修改需求、遮挡这个区域、删除。
- 鼠标悬停候选元素时，用 2px 虚线框提示。
- 候选框要比已选框更轻，避免用户误以为已经保存。
- 候选框右上角显示 4 个小按钮：缩小选区、扩大选区、普通标注、遮挡。
- 候选框靠近屏幕边缘时，框线和 4 个按钮都要自动收进可见区域。

标注框不能影响原网页布局。它应该浮在网页上方，而不是把网页内容挤开。

## 7. 编号标签

标签建议默认用普通数字 `1, 2, 3`，视觉上放在圆形标签里。

原因：

- 圆圈数字 `①②③` 好看，但部分字体或系统下显示可能不一致。
- 普通数字加圆形背景更稳定，也更适合英文用户。

可选：

- 中文界面可以提供圆圈数字样式。
- 英文界面默认普通数字样式。

规格：

- 默认直径：40px。
- 字号：22px。
- 字重：700。
- 背景：跟标注框一致。
- 文字：白色。
- 位置：标注框右上角外侧。
- 靠近屏幕右侧时，标签要向左移动，确保完整显示。
- 靠近屏幕顶部时，标签要向下移动，确保完整显示。
- 标签不能遮住右上角的写要求、遮挡、删除按钮。
- 描边：根据背景自动使用白色或黑色描边。
- 阴影：中等强度阴影，保证截图缩小后仍能看清。
- 最小可读尺寸：截图缩小到 50% 时仍能分辨数字。

## 8. 备注输入框

备注输入框是用户写修改要求的地方。

展开状态：

- 多行文本框。
- 最小高度 72px。
- 最大高度 220px。
- 超过高度后内部滚动。
- 回车换行。
- 失焦保存。

折叠状态：

- 一行摘要。
- 显示编号和第一行文字。
- 超长显示省略号。
- 点击或悬停重新展开。

位置：

- 默认贴近标注框右下角。
- 下方空间不足时自动放上方。
- 始终尽量留在当前可见屏幕里。

视觉：

- 背景：根据页面亮暗自动切换，亮色页面用白色半透明，暗色页面用深色半透明。
- 边框：跟标注框颜色一致。
- 圆角：12px。
- 阴影：轻微阴影。
- 内边距：10px 到 12px。
- 文本颜色必须和背景保持清晰对比。
- 折叠状态高度要稳定，不能因为文字长短导致页面视觉跳动。

交互细节：

- 鼠标移入备注时展开。
- 鼠标移出备注且不在编辑时折叠。
- 输入框失焦后保存。
- 回车用于换行，不触发保存或关闭。
- `Esc` 可以取消当前编辑焦点，但不删除已写内容。
- 正在导出或截图准备时，备注输入框自动进入隐藏状态，只保留编号。

## 9. 底部补充说明区

底部补充说明区默认折叠。

折叠状态：

- 页面底部显示一个小条。
- 文案：`补充说明` / `More notes`。
- 不遮挡页面主要内容。

展开状态：

- 从底部浮起。
- 高度默认 260px。
- 用户可以拖动改变高度。
- 包含一个大文本框。
- 支持多行输入和自动保存。

适合写：

- 背后的业务逻辑。
- 无法框选的位置。
- 页面整体修改方向。
- 开发注意事项。

## 10. 截图准备模式

截图准备模式是第一版非常重要的兜底功能。

点击后：

- 工具栏隐藏。
- 设置面板隐藏。
- 所有备注输入框隐藏。
- 只保留网页内容、标注框、编号标签。
- 屏幕角落显示一个很小的倒计时。

倒计时：

- 默认 5 秒。
- 可以在设置里改成 3 秒或 10 秒。
- 倒计时结束后自动恢复工具栏。

用户可以在这几秒内按 `Win + Shift + S` 手动截图。

## 11. 动效

动效要轻，但不能没有质感。PinFix 的动效应该帮助用户理解状态变化，而不是单纯装饰。

建议：

- 左侧入口出现：轻微淡入和上移，180ms。
- 工具栏展开：从入口按钮方向滑出，150ms 到 180ms。
- 浮层打开：轻微缩放和淡入，140ms。
- 候选模块高亮：边框透明度渐变，80ms 到 120ms。
- 标注生成：标签轻微弹出，120ms 到 160ms。
- 备注展开/折叠：高度和透明度同步变化，160ms 到 200ms。
- 复制成功：按钮短暂变成成功状态，800ms 后恢复。
- 截图准备：工具栏快速淡出，倒计时轻微呼吸，不要闪烁。
- 清空本页：必须有确认反馈，不能只用动画表达。

所有动画都要支持减少动态效果设置。

减少动态效果时：

- 保留状态变化。
- 取消缩放、滑动和呼吸动画。
- 使用简单淡入淡出或直接切换。

## 12. 双语文案原则

简体中文要直白，不要过度专业。

英文要简短，不要机器翻译味太重。

示例：

- 选择模块 / Select
- 复制文字 / Copy notes
- 导出截图 / Export image
- 截图准备 / Screenshot mode
- 补充说明 / More notes
- 清空本页 / Clear page

## 13. 额外好用功能建议

这些功能可以在第二步或第三步加入：

- 放大镜：鼠标附近显示小范围放大，方便选很小的按钮或文字。
- 智能摘要：备注折叠时自动取第一句作为摘要。
- 快速模板：提供“向上移动一点”“字号变小”“间距加大”“文案改成”等常用短句。
- 隐私遮挡：导出前给敏感信息打码。
- 标注清单：侧边显示所有编号，点击编号跳到对应位置。
- 验收模式：隐藏输入框，只显示编号和摘要，方便最后检查。
- 最近样式：自动记住用户上一次使用的颜色、粗细、标签大小。
- 页面模式记忆：同一个网站再次打开时，沿用上次选择的亮页或暗页显示策略。
- 快速复制摘要：只复制编号和一句话摘要，适合很小的改动。
- 导出前检查：提醒“有 2 个标注还没有写说明”，避免漏填。

## 14. 第四轮 UI/UX 打磨规则

本轮采用“点击激活”的修改要求交互。不要依赖悬停作为唯一入口，因为悬停不适合触屏，也容易在密集标注时误触。

修改要求面板：

- 默认不常驻显示，避免遮挡网页内容。
- 新建标注后自动展开当前标注的面板。
- 点击红框、编号标签或写要求按钮，都能展开对应面板。
- 同一时间只展开一个面板，切换标注时自动收起旧面板。
- 面板上边缘要贴住红框下边缘，视觉上像“属于这个框”。
- 下方空间不足时，面板翻到红框上方；左右空间不足时，整体收进可视区。
- 面板宽度控制在 280px 到 320px，避免像弹窗一样压住页面。
- 未填写时只用编号右上角的小红点提示，不再展开大面积空卡片。

候选框和操作按钮：

- 候选框的四个按钮放到候选元素中心，形成一个清楚的操作岛。
- 已有标注的三个按钮只在标注激活或悬停时出现。
- 按钮组要避开编号标签和浏览器边缘，不能被标签盖住。
- 按钮视觉尺寸可以小于 44px，但点击热区要尽量接近 36px 到 40px，避免难点。

编号标签：

- 标签继续放在红框右上角附近，但靠近右侧或顶部时必须自动内收。
- 未填写修改要求时，标签右上角显示 6px 到 8px 红点。
- 红点只是状态提醒，不要遮住数字本身。
- 写入修改要求后红点消失，不额外显示打勾，保持干净。

层级规则：

- 标注框负责定位，视觉最醒目。
- 编号标签负责建立截图和文字说明的对应关系。
- 操作按钮只在需要时出现，不长期压住页面内容。
- 修改要求面板只服务当前激活标注，不参与截图主体表达。

滚动规则：

- 已保存标注必须跟随原网页自然滚动，不能被强行吸附到屏幕顶部或左右边缘。
- 标注对应模块完全离屏，或只剩很薄一条时，红框、编号、红点、按钮和修改要求面板整组隐藏。
- 用户滚回对应模块后，标注整组恢复显示。
- 屏幕安全边距主要用于候选框、当前可见标注的浮动按钮和修改要求面板，不能把离屏标注拉回屏幕。
