# PinFix 产品规划

## 1. 产品定位

PinFix 是一个给非程序员使用的网页修改标注助手。

它不是设计软件，也不是完整测试平台。它的核心目标是：让用户在真实网页上点选需要修改的位置，自动生成编号，写下修改要求，然后导出一张干净截图和一份结构化文字说明。

中文名建议：点改。

英文名：PinFix。

一句话介绍：

> 点哪里，写怎么改，一键整理给 Codex。

## 2. 目标用户

主要用户：

- 产品负责人。
- 独立开发者。
- 设计师。
- 测试人员。
- 不会写代码但需要给网页提修改意见的人。

使用场景：

- 给 Codex 描述页面细节修改。
- 给开发者说明 UI、文案、排版、交互问题。
- 在后台页面、商品页、表单页等复杂页面上标注多个修改点。
- 把业务逻辑补充说明和页面位置说明放在一起。

## 3. 第一版核心原则

第一版只做最常用、最稳的部分：

- 标注当前可见页面。
- 不做长图截图。
- 图片和文字分开导出。
- 插件自己的按钮不出现在截图里。
- 所有备注自动保存，避免刷新或误关导致内容丢失。
- 用户设置自动保存，下一次打开沿用上次模式。
- 常用按钮外露，低频功能收进“更多”或“设置”。
- 支持简体中文和英文界面。

第一版不承诺：

- 对所有网页都能生成完全真实截图。
- 一次粘贴同时带图片文件和文字文件。
- 自动理解所有页面结构。
- 自动生成最终修改方案。

## 4. 默认界面

默认状态下，页面左侧中间只显示一个小按钮。

按钮形态：

- 位置：左侧中间，距离左边 12px。
- 形状：竖向小胶囊。
- 尺寸：约 44px 宽，56px 高，方便点击。
- 图标：用一个简洁的定位针或标注图标。
- 文字：默认不显示文字，鼠标悬停显示 tooltip。
- 颜色：默认深青色或墨绿色，不用刺眼红色。
- 层级：始终在页面上方，但不要遮挡主要内容。

点击按钮后进入标注模式。

## 5. 标注模式工具栏

进入标注模式后，左侧按钮下方展开一列小工具栏。工具栏不能把所有功能都摊开，否则会像后台面板，和“无感”目标冲突。

第一版建议只外露 5 个主按钮：

- 选择：进入点选网页模块状态。
- 样式：打开一个小浮层，设置颜色、框线粗细、标签样式。
- 截图：打开截图菜单，包含“截图准备”和“导出当前画面”。
- 复制：复制整理好的文字说明。
- 更多：放撤销、隐藏备注、清空本页、语言、设置、退出等低频功能。

低频功能收纳规则：

- 颜色、粗细、标签大小属于“样式”浮层，不单独占工具栏按钮。
- 截图准备、导出 PNG、复制图片属于“截图”浮层。
- 撤销、删除、标注清单、清空本页、语言切换属于“更多”浮层。
- 退出标注模式可以通过再次点击左侧主按钮完成，不必长期占一个按钮。

工具栏设计：

- 使用图标为主，tooltip 解释含义。
- 鼠标悬停时显示简短文字。
- 按钮之间保持 8px 间距。
- 每个按钮点击区域不小于 44px。
- 当前选中的工具要有明显高亮。
- 工具栏可见按钮最多 5 个，避免挡住页面。

## 6. 选中网页模块

用户点击“选择模块”后，鼠标移动到页面上时，PinFix 自动高亮当前候选模块。

候选模块规则：

- 优先选择有明显边界的元素，比如卡片、按钮、表单、图片、标题区域。
- 避免直接选中整个页面 body。
- 如果选区太小，可以用“扩大选区”选择父级模块。
- 如果选区太大，可以用“缩小选区”选择子模块。

交互表现：

- 鼠标悬停时显示淡色虚线框。
- 点击后变成实线框。
- 实线框右上角出现一个小圆点按钮。
- 点击小圆点后生成编号标签。
- 如果用户直接点击选区，也可以自动生成编号，减少步骤。

建议增加两个快捷键：

- `[`：缩小选区。
- `]`：扩大选区。

这两个快捷键对细节页面很有用，因为自动识别不可能永远准确。

## 7. 标注框和标签样式

默认标注样式：

- 框线颜色：红色 `#E11D2E`。
- 框线粗细：4px。
- 框线样式：实线。
- 角标位置：选区右上角外侧，尽量不遮挡原页面内容。
- 标签形态：圆形实心底 + 白色数字。
- 标签大小：36px 到 44px，保证截图里看得清楚。
- 标签阴影：轻微阴影，避免在复杂背景上看不见。

预设样式：

- 红色重点：用于必须修改的问题。
- 蓝色建议：用于优化建议。
- 绿色确认：用于已经确认的方向或验收点。
- 黑白中性：用于正式文档或浅色页面。

亮色和暗色页面显示策略：

- 标注框使用“双层描边”：外层是用户选择的颜色，内层是白色或黑色细线，用来保证对比度。
- 标签使用实心色背景，同时加 2px 白色或黑色描边，避免贴在相近颜色背景上看不清。
- PinFix 应该检测标注区域背后的平均亮度，自动决定使用浅色描边还是深色描边。
- 在暗色页面上，备注输入框使用深色半透明背景和浅色文字。
- 在亮色页面上，备注输入框使用白色半透明背景和深色文字。
- 如果自动判断失败，用户可以在“样式”浮层里手动切换“亮页模式 / 暗页模式”。

高级设置可以后置，不要在第一版做太复杂，但亮暗页面可读性必须第一版就考虑。

## 8. 单个标注的备注输入

每个标注可以有一个备注输入框。

输入框位置：

- 优先显示在选区下方。
- 如果下方空间不够，显示在选区上方。
- 如果上下都不够，显示在可见区域内最近的位置。

输入规则：

- 点击输入框后展开全文。
- 鼠标悬停在输入框上时展开全文。
- 正在编辑时一直展开。
- 失焦后自动保存并折叠成一行摘要。
- 鼠标移出且不在编辑时自动折叠。
- 回车键用于换行，不用于保存。
- 保存动作发生在失焦、切换标注、导出前、页面关闭前。

折叠状态：

- 显示编号和第一行摘要。
- 摘要过长时显示省略号。
- 鼠标悬停显示完整内容。

输入框视觉：

- 背景使用半透明白色或深色自适应。
- 边框颜色跟标注框一致。
- 左侧显示编号小标签。
- 文本字号不小于 14px。
- 最大宽度约 360px，避免横向占太多空间。

## 9. 页面底部补充说明区

页面底部有一个默认折叠模块，用来写无法绑定到具体编号的说明。

用途：

- 背后的业务逻辑。
- 页面整体风格要求。
- 多个模块之间的关系。
- 无法通过框选表达的改动。
- 开发注意事项。

交互：

- 默认只露出一个底部小条。
- 点击后从底部展开。
- 可以拖动调整高度。
- 支持多行输入。
- 自动保存。
- 导出文字时放到最后。

底部模块不要默认占据页面空间，避免干扰标注。

## 10. 导出方式

第一版提供三个导出动作。

导出截图：

- 只导出当前可见区域。
- 保留网页内容、标注框、编号标签。
- 隐藏 PinFix 工具栏、设置面板、输入框编辑态。
- 可以选择保存为 PNG 或复制到剪贴板。
- 如果浏览器不支持复制图片，则自动下载 PNG。

复制文字：

- 复制结构化 Markdown 文本。
- 包含页面标题、页面 URL、标注列表、每个编号的说明、底部补充说明。
- 导出前自动保存所有输入框内容。

截图准备：

- 点击后隐藏所有 PinFix 工具栏和输入框。
- 保留网页内容、标注框、编号标签。
- 显示 5 秒倒计时。
- 用户可以按 `Win + Shift + S` 手动截图。
- 倒计时结束后工具栏自动恢复。

## 11. 导出文字模板

```text
需要修改的页面：{pageTitle}
页面地址：{pageUrl}
截图模式：当前可见区域

需要修改的地方：
①：{summary}
②：{summary}

具体修改要求：
①：
{note}

②：
{note}

需要修改的背后业务逻辑：
{globalNote}

补充信息：
- 浏览器视口：{width} x {height}
- 标注数量：{count}
- 生成时间：{time}
```

英文界面下导出英文模板。

## 12. 语言支持

第一版支持两种语言：

- 简体中文。
- English。

语言策略：

- 所有界面文字放在语言字典里。
- 不要把中文或英文硬写在功能代码里。
- 默认跟随浏览器语言。
- 用户可以在设置中切换语言。
- README 和开源介绍提供中英文版本。

## 13. 数据保存

需要自动保存的数据：

- 当前页面的标注。
- 每个标注的位置、颜色、编号、备注。
- 底部补充说明。
- 用户设置，例如语言、颜色、线条粗细。
- 最近一次使用的工具模式，例如选择模式、样式预设、截图倒计时。
- 每个网站的偏好设置，例如某个后台页面默认用红色粗线。

保存位置：

- 第一版使用浏览器本地存储。
- 数据按页面 URL 区分。
- 提供清空当前页面标注的按钮。
- 全局设置和当前页面标注分开保存。
- 用户再次打开 PinFix 时，默认沿用上一次设置，而不是每次重置。

需要注意：

- 不上传用户数据。
- 不默认记录密码框、银行卡号等敏感输入。
- 用户标注的数据只保存在本机。
- 需要给保存数据加版本号，后续升级脚本时方便迁移旧数据。
- 如果页面 URL 带有临时参数，保存时要尽量用稳定地址，避免同一个页面被当成很多页面。

## 14. 技术实现模块

建议代码模块：

- `main`：入口，初始化 PinFix。
- `i18n`：语言切换。
- `toolbar`：左侧按钮和工具栏。
- `selector`：识别和选择页面模块。
- `overlay`：画框、标签、输入框。
- `notes`：备注输入、折叠、自动保存。
- `storage`：本地保存和恢复。
- `exportText`：生成并复制文字说明。
- `capture`：截图导出和截图准备模式。
- `settings`：颜色、粗细、语言等设置。

每个模块都必须写清楚注释，尤其是选择模块、截图、自动保存这些核心逻辑。

## 15. 风险和处理

截图不准：

- 原因：油猴脚本不是系统截图，复杂页面可能无法完整还原。
- 处理：提供“截图准备”模式，用户可用 Windows 手动截图。

选区不准：

- 原因：网页结构复杂，自动识别可能选大或选小。
- 处理：提供扩大选区、缩小选区和重新选择。

标注挡住页面：

- 原因：输入框和标签可能覆盖原内容。
- 处理：输入框失焦折叠；截图时隐藏输入框，只保留编号。

跨语言维护困难：

- 原因：中英文 UI 混在代码里会难维护。
- 处理：所有文字放进语言字典。

用户误删标注：

- 原因：页面上操作频繁。
- 处理：提供撤销和删除确认。

插件挡住真实页面操作：

- 原因：标注层覆盖在网页上方，可能拦截原页面点击。
- 处理：只有进入选择模式时才拦截点击；退出选择模式后，页面应尽量恢复正常交互。

单页应用切换页面后标注错位：

- 原因：很多现代网页切换内容时不会刷新浏览器页面。
- 处理：监听地址变化和主要内容变化，变化后提示用户是否保留当前标注。

页面缩放或窗口大小变化导致标注偏移：

- 原因：标注位置如果只保存像素，窗口变化后可能不准。
- 处理：同时保存元素路径、元素文字摘要、相对位置和截图时的视口尺寸。

网页层级太高导致 PinFix 被盖住：

- 原因：某些页面弹窗或导航的层级很高。
- 处理：PinFix 使用独立顶层容器，并提供“置顶修复”逻辑。

iframe、视频、地图、canvas 内容无法准确标注或截图：

- 原因：浏览器安全限制和特殊渲染方式。
- 处理：允许用户手动框选区域，并优先使用“截图准备”模式配合系统截图。

快捷键和原页面冲突：

- 原因：网页自身也可能使用快捷键。
- 处理：快捷键默认只在标注模式开启时生效，并允许用户关闭。
