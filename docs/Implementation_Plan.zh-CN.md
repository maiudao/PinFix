# PinFix 实施计划

## 1. 这次要交付什么

本次直接交付一个可安装、可试用、可继续迭代的 PinFix 第一版项目。

交付目标不是“先做几个页面原型”，而是交付一个真正可运行的油猴脚本版本，并把文档里已经明确写死的核心能力做完整。

本次默认以“第一版正式范围”作为硬边界，同时把第二步里已经明确、而且不会明显拖垮结构的关键体验一起纳入：

- 左侧启动按钮和紧凑工具栏。
- 模块选择、高亮、标注、编号。
- 候选框快捷按钮：缩小、扩大、普通标注、遮挡。
- 单个标注备注输入与折叠。
- 页面底部补充说明区。
- 自动保存和刷新恢复。
- 结构化文字复制。
- 截图准备模式。
- 当前可见区域图片导出。
- 样式设置、更多菜单、撤销、单个删除。
- 简体中文和英文界面。
- 快捷键、亮暗页适配、页面地址变化处理。

明确不把第三阶段“扩展版”内容塞进这次交付，避免把结构做乱：

- 不做 Chrome / Edge 扩展包。
- 不做长图截图。
- 不做云端同步。
- 不做团队协作、评论流、Issue/Notion 对接。
- 不做资料包 zip 导出。

## 2. 产品边界和原则

必须遵守这些原则：

- 默认安静：页面初始只显示一个左侧小入口。
- 不做大面板：常用能力外露，低频能力收进浮层。
- 不让用户先学工具：打开就能选、标、写、导出。
- 不把工具自己拍进截图：截图前自动隐藏工具栏、浮层和输入框。
- 数据优先保本地：默认只保存在浏览器本地，不上传。
- 文案双语：界面文字必须从语言字典读取，不能散落在功能代码里。
- 注释必须够用：核心逻辑说明“为什么这样做”，不是只写“这里赋值了”。

## 3. 功能清单

### 3.1 入口和主工具栏

必须实现：

- 左侧中间固定入口按钮。
- 入口按钮支持打开 / 关闭 PinFix。
- 默认入口是更小的双圆点，不显示 `PF` 文本。
- 打开后显示 5 个主按钮：选择、样式、截图、复制、更多。
- 打开后关闭按钮默认隐藏，只在鼠标移入工具栏或键盘聚焦时出现。
- 所有按钮有 tooltip。
- 当前激活状态有明显高亮。
- 点击页面空白可关闭浮层。

### 3.2 模块选择

必须实现：

- 进入选择模式后，鼠标移动时高亮候选模块。
- 尽量避免直接选中 `body` 或过大容器。
- 点击候选模块后立即生成标注。
- 支持扩大选区和缩小选区。
- 候选框右上角支持 4 个按钮：缩小选区、扩大选区、普通标注、遮挡这个区域。
- 快捷键支持 `[` 缩小、`]` 扩大。
- 退出选择模式后，尽量不影响原网页正常点击和滚动。

### 3.3 标注框和编号

必须实现：

- 自动分配编号。
- 标注框悬浮在原网页上，不挤动原布局。
- 标注框支持颜色预设、粗细、标签大小。
- 标签放在框体右上角外侧，尽量不遮内容。
- 框线、标签和右上角按钮靠近屏幕边缘时要自动内收，避免被浏览器边缘截断。
- 标签要避开写要求、遮挡、删除按钮。
- 标签和框线支持亮暗背景下的反差描边。
- 每个标注支持单独删除，删除单个标注不弹确认。
- 支持撤销上一步。

### 3.4 备注输入

必须实现：

- 每个标注都有备注输入框。
- 默认优先贴近选区右下角，空间不足时放上方或收进可见区域。
- 编辑态展开，失焦自动保存并折叠。
- 悬停时展开，移出后折叠。
- 回车换行，不把回车当保存。
- 导出前自动保存。
- 截图时隐藏备注输入框。

### 3.5 底部补充说明区

必须实现：

- 页面底部默认只显示一条折叠条。
- 点击后展开大输入区。
- 自动保存。
- 支持改高度。
- 导出文字时放在末尾。

### 3.6 导出文字

必须实现：

- 复制结构化 Markdown 文本。
- 包含页面标题、页面地址、当前模式说明、编号摘要、详细说明、补充说明、视口尺寸、标注数量、生成时间。
- 中文界面导出中文模板，英文界面导出英文模板。
- 复制成功后给用户明确反馈。

### 3.7 截图相关

必须实现：

- 截图准备模式。
- 截图准备时隐藏工具栏、浮层、备注输入框，只保留网页、标注框、编号。
- 默认 5 秒倒计时，可切成 3 秒或 10 秒。
- 倒计时结束后自动恢复界面。
- 导出当前可见区域 PNG。
- 优先尝试复制图片到剪贴板；如果失败，自动下载 PNG。

必须明确提示用户的限制：

- 当前可见区域图片导出属于浏览器内重绘，不等于系统原生截图。
- 跨域图片、视频、地图、iframe、canvas 等内容可能不完整。
- 这种场景要优先使用“截图准备”配合系统截图。

### 3.8 样式和设置

必须实现：

- 颜色预设：红、橙、琥珀、蓝、青绿、绿、黑白中性。
- 框线粗细：细、中、粗。
- 标签大小设置。
- 亮页 / 暗页策略：自动、亮页、暗页。
- 语言切换：简中、英文。
- 截图倒计时设置：3 秒、5 秒、10 秒。
- 隐藏 / 显示备注。

### 3.9 数据保存

必须实现：

- 保存当前页面标注数据。
- 保存每个标注的编号、备注、颜色、粗细、标签大小、位置和关联元素线索。
- 保存底部补充说明。
- 保存全局设置和最近使用偏好。
- 全局设置与页面数据分开保存。
- 存储结构带版本号。
- 页面键使用稳定地址，尽量忽略临时查询参数。
- 支持清空当前页面标注。

### 3.10 稳定性和兼容处理

必须实现：

- 监听页面地址变化，处理单页应用切换。
- 页面刷新后尽量恢复标注位置。
- 元素找回失败时回退到保存的矩形位置。
- 尽量避免覆盖密码框等敏感值本身，只保存用户写的备注内容。
- 提供“置顶”容器，尽量避免被网站高层级元素盖住。
- 支持减少动态效果。

## 4. 结构设计

项目采用“源码分模块，产物单文件”的方式，兼顾可维护和安装方便。

建议结构：

```text
PinFix/
  docs/
  demo/
  dist/
  scripts/
  src/
    modules/
  vendor/
```

本次会落这些核心文件：

- `src/modules/i18n.js`：双语字典和取词方法。
- `src/modules/storage.js`：本地保存、读取、版本和地址归一化。
- `src/modules/selector.js`：候选元素识别、扩大 / 缩小选区。
- `src/modules/exporters.js`：文字导出和图片导出。
- `src/modules/ui.js`：入口按钮、工具栏、浮层、标注层、备注、底部说明区。
- `src/modules/app.js`：状态管理、事件联动、初始化。
- `scripts/build.mjs`：把源码拼成可安装脚本。
- `dist/pinfix.user.js`：最终可安装产物。
- `demo/index.html`：本地静态演示页，方便最小验证。

## 5. 风险和处理办法

- 选区不准：提供扩大 / 缩小选区和重新选择。
- 边缘显示不完整：框线、标签、候选按钮、标注按钮和备注卡片都要做可见区域保护。
- 标注恢复错位：同时保存元素路径和矩形位置，优先找元素，找不到再回退坐标。
- 截图不完整：明确区分“导出图片”和“截图准备”两条路，后一条是兜底主方案。
- 网页拦截点击：只有选择模式拦截点击；其他时候尽量放行。
- 工具遮挡页面：备注默认折叠，工具栏控制在 5 个主按钮。
- 多语言维护乱：所有文案走语言字典。
- 文件过大：源代码拆模块，最终产物再合并。

## 6. 开发顺序

1. 建项目骨架和实施文档。
2. 建双语字典、全局样式和构建脚本。
3. 做入口按钮、工具栏和浮层。
4. 做候选元素识别、选区切换和标注生成。
5. 做备注输入和底部补充说明区。
6. 做本地保存、刷新恢复和地址变化处理。
7. 做复制文字和截图准备。
8. 做当前可见区域图片导出。
9. 做更多菜单、撤销、清空、语言、快捷键。
10. 做演示页、构建、最小验证和交付说明。

## 7. 验证清单

每次完成后至少检查这些点：

- 入口按钮能正常打开和关闭。
- 关闭态入口是居中的双圆点，不显示 `PF` 或竖向胶囊。
- 工具栏关闭按钮默认隐藏，鼠标移入工具栏后出现。
- 选择模式下能连续添加 3 到 5 个标注。
- 候选框的缩小、扩大、普通标注、遮挡按钮都能使用。
- 备注失焦后会保存，刷新后能恢复。
- 补充说明区刷新后能恢复。
- 复制文字内容结构完整。
- 截图准备时工具栏和输入框不入镜。
- 导出图片失败时会回退到下载。
- 颜色、粗细、标签大小、语言和倒计时会记住。
- 中英文切换后主界面文案正确。
- 页面还能正常滚动。
- 顶部、左侧、右侧边缘的标注框、标签和按钮不会出屏或互相遮挡。
- 单页应用地址变化后不会把旧页面标注错误带到新页面。

## 8. 交付标准

达到下面状态，就算这次交付完成：

- 仓库里有清晰文档、源码、构建脚本、可安装产物和最小演示页。
- 不懂代码的人可以根据 README 安装并开始使用。
- 用户可以在真实网页上完成“点选、编号、写说明、复制文字、截图准备、导出当前画面”的完整流程。
- 代码里关键模块有足够注释，后续继续迭代不会变成黑盒。

## 9. 第四轮可用性打磨追加标准

本轮重点解决“多标注后页面被修改要求卡片遮挡”的问题。PinFix 应该默认保持页面干净，只有用户明确点中某个标注时，才展开这一条修改要求。

当前审视评分：

- 关闭入口：8/10，双圆点方向正确，继续复核居中和命中区。
- 左侧工具栏：7/10，关闭按钮显隐合理，继续统一尺寸、对齐和焦点状态。
- 候选框四按钮：6/10，功能可用，但右上角容易挡内容，改为元素中心悬浮。
- 标注框和编号标签：6/10，已有边缘保护，但顶部、右侧、滚动条附近还要加强。
- 修改要求面板：3/10，默认全展开会堆叠，是本轮最高优先级问题。
- 遮挡模块：6/10，作为辅助能力保留，视觉层级不能抢普通标注。
- 多模块连续选择：3/10，需要明确当前激活项和非激活项。

必须实现：

- 新建标注后自动激活，并直接展开这一条修改要求。
- 非激活标注只显示红框、编号和必要状态点，不显示大修改要求面板。
- 同一时间最多只有一个修改要求面板展开。
- 点击红框、编号标签或写要求按钮，都能激活对应标注。
- 未填写修改要求时，编号标签右上角显示小红点；填写后小红点消失。
- 激活面板上边缘紧贴标注框下边缘；下方空间不足时翻到上方，并保持不出屏。
- 候选框四个按钮移动到候选元素中心：缩小、扩大、普通标注、遮挡。
- 已有标注的写要求、遮挡、删除按钮只在激活或悬停时显示，并避开编号标签。
- 框线、编号、小红点、按钮组和修改要求面板都必须使用可视区安全边距。
- 已保存标注跟随网页自然滚动；对应模块离屏或只剩很薄一条时，整组标注自动隐藏，不能被边缘保护逻辑吸到屏幕顶部。
